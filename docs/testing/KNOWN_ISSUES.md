# Known issues from the pre-load audit

Date: 2026-09-27. Severity describes production impact. A verification gap is not evidence that the implementation is broken.

## Remaining

| ID | Severity | Issue and root cause | Evidence / reproduction | Required action |
| --- | --- | --- | --- | --- |
| H-01 | HIGH | The default Camoufox browser lifecycle is unverified in this checkout. Its pinned 493 MB binary is absent from the local cache. | The opt-in Camoufox smoke fails before launch with `version.json` missing. The Playwright fallback smoke passes four runs. | Run the pinned Camoufox smoke and repeated capture/crash/cancellation tests in the Windows release environment; verify process, context, page, profile and proxy cleanup. |
| H-02 | HIGH | The Windows deployment has no documented or scripted network-level outbound restriction for the browser process. SafeProxy is application-level isolation only. | `capture-worker/src/browser.ts` configures SafeProxy; `infra/production-windows/` has no browser egress firewall rule. | Add and test a Windows egress policy for the browser service account/process that permits only the local proxy, with a bypass attempt in the release preflight. |
| H-03 | HIGH | Public login/registration endpoints have no rate limit or lockout. Repeated password guesses can reach password verification without a bounded request policy. | Review of `backend/src/main/java/com/weblens/auth/` and the production Caddy configuration found no throttle; a live invalid-password request returned 401. | Add a bounded policy at the public edge or auth service, test repeated attempts and recovery, and monitor rejected attempts. |
| H-04 | HIGH | Cross-service analytical publication and recovery are not proven. ClickHouse and object storage were unavailable, so the accepted scan/capture → analytics → terminal report and outage/restart paths were not exercised. | Docker daemon unavailable; the Go ClickHouse and Capture Worker S3 integration suites skipped. | Run isolated ClickHouse/S3 integration and a three-service E2E with duplicate delivery, outage, restart, cancellation and reconciliation before load testing. |
| H-05 | HIGH | Production backup/restore is described as a requirement but no scheduled backup plus restore drill result is recorded for all three PostgreSQL databases, ClickHouse and object storage. | `infra/production-windows/README.md` gives a backup location and pre-upgrade dump instruction; no restore evidence was found. | Document and execute an encrypted off-host backup and restore drill, including cross-store reconciliation and measured RPO/RTO. |
| M-01 | MEDIUM | Crawler sitemap discovery is absent, so the requested P0 sitemap case cannot pass. Frontier discovery currently comes from parsed page links. | No sitemap fetch/parser path exists under `crawler/internal/`; the fixture suite covers HTML links. | Confirm sitemap scope against the product requirement, then add bounded sitemap and sitemap-index discovery with local XML fixtures, dedup and depth/page limits. |
| M-02 | MEDIUM | Production metrics are too thin for scan/queue/retry/browser debugging. Control Plane exposes only health/info; crawler and capture expose health endpoints. | `backend/src/main/resources/application.yml` exposes `health,info`; no crawler/capture metrics endpoint or counters were found. | Expose protected, bounded metrics for queue age, active work, retries, failures, DB pool and browser lifecycle; test labels do not contain URLs or secrets. |
| M-03 | MEDIUM | Page retry does not honor `Retry-After` on HTTP 429/503. The current bounded exponential delay with deterministic jitter can retry sooner than the target requests. | `crawler/internal/postgres/store.go` has `pageRetryDelay` and no response header input; `crawler/internal/crawl/fetcher.go` does not retain `Retry-After`. | Capture and bound valid `Retry-After` values, combine them with existing backoff, and test date/seconds/invalid cases on local fixtures. |
| M-04 | MEDIUM | Cancellation during an actual fetch, browser render, parse, object upload and persistence has not been verified end to end. Database fencing tests pass, but they do not prove work stops promptly. | PostgreSQL integration tests cover stale leases and cancellation races; no running Camoufox cancellation test completed. | Add controlled in-flight cancellation fixtures and assert no late publication, bounded stop time, and cleanup. |
| M-05 | MEDIUM | Production PostgreSQL 17 migration and restart compatibility remain unverified in this phase. | All 13 Control Plane Flyway migrations applied and validated on isolated PostgreSQL 18.4; production guide specifies PostgreSQL 17. | Repeat empty-schema and existing-schema migration, graceful restart and pending-work checks against a production-version test instance. |
| L-01 | LOW | Go's race detector could not run on this Windows host because CGO and a C compiler are unavailable. | `go test -race` exits with `-race requires cgo`; ordinary and deterministic concurrency suites pass. | Run the race detector in CI with a supported compiler. |

## Fixed in this audit

| ID | Severity | Root cause and proof | Fix |
| --- | --- | --- | --- |
| F-01 | HIGH | Capture address policy misclassified IPv4-mapped IPv6 loopback as public. The new URL regression first failed. A proxy fixture now proves the private listener receives zero requests. | Use Node's subnet-aware `BlockList`, reject mapped/reserved ranges, normalize bracketed IPv6 literals, and test both URL validation and SafeProxy egress. |
| F-02 | MEDIUM | Crawler retried every 5xx response, including permanent 501 and 505. New cases failed before the fix. | Retry only 429, 500, 502, 503 and 504 plus classified transient network errors; retain the three-attempt cap. |
| F-03 | LOW | A terminal cancelled scan displayed a message promising automatic report retries even though polling had stopped. Reproduced in the browser. | Show a terminal-specific unavailable message and add a UI regression test. |
| F-04 | LOW | The loopback timing test assumed connect duration must be positive, which can be zero at clock resolution. One full-suite run failed; three reruns passed after correction. | Assert the observed timing phase, allowing a zero duration. |

No BLOCKER was confirmed. The remaining HIGH items are release/verification gates; do not infer a pass from skipped tests.
